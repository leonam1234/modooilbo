## 왜 지우지 않았나

`PLAN.md`·`REVIEW.md` 는 이 사이트가 **어떻게 만들어졌는지**에 대한 유일한 기록이다.
쓸모가 끝난 것과 없어도 되는 것은 다르다.

`DEPLOY.md`·`DEPLOYMENT.md` 는 합치는 과정에서 **모순이 하나 있었다** — `wiki/06` 은
"대시보드 Git 연동" 을 배포 방법으로 권했는데, `DEPLOYMENT.md` 는 Git 연동 없음이
**의도된 원칙**이며 붙이면 원칙이 깨진다고 경고하고 있었다. 합치면서 후자를 정본으로
삼았다. 원문을 남겨 둬야 나중에 이 판단을 검증할 수 있다.
